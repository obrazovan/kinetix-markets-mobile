# Quickstart: Kinetix Markets

## Prerequisites
- Flutter SDK 3.x (with Dart 3.x)
- JDK 17 + Android SDK (API 35) for Android APK builds / emulator runs

## Commands

```powershell
# 1. Install dependencies
flutter pub get

# 2. Static analysis
flutter analyze

# 3. Run all unit & widget tests (single command)
flutter test

# 4. Build Android APK
flutter build apk --debug

# 5. Run on connected Android device or running emulator
flutter run
```
